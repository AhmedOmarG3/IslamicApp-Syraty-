# Prayer Data State Contract

| State | User-visible requirement | Qualification |
|---|---|---|
| Loading | Clear loading indication | No current values claimed |
| Current | Validated information | Location and date identified |
| Stale | Explicit stale label | Location/date/freshness disclosed |
| Offline | Recovery guidance | No invented fallback |
| Invalid | Explain data is untrusted | Invalid values not displayed as current |
| Failed | Clear Arabic error/retry | Failure remains diagnosable |

Prayer information is retrieved/calculated data, not a religious ruling. Fixed demo times, names, or countdowns are prohibited.
